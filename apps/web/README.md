# NexaAI Web Frontend

Production Next.js application for the NexaAI conversational and multimodal intelligence platform.

## Features
- Next.js App Router architecture
- Real-time Server-Sent Events (SSE) AI streaming
- Multimodal document, vision, OCR, and speech intelligence
- OAuth authentication (Google & GitHub) and JWT credential flows
- Modern responsive interface with light and dark mode

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm start
```
